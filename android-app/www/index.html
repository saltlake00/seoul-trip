핀을 누르면 장소 이름이 나옵니다. 지도는 인터넷이 필요합니다.

    일정 알림

    이동이 필요한 일정은 출발할 시각(시작 − 이동 시간 − 여유)에, 나머지는 시작 전에 알립니다. 앱을 닫아도 울립니다. 단, 설정에서 「강제 중지」하면 울리지 않습니다.

    여유 시간

    예약된 알림

      알림이 안 오거나 늦을 때

      • 설정 → 애플리케이션 → 서울 1박 2일 → 배터리 → 「제한 없음」
      • 삼성: 설정 → 배터리 → 백그라운드 사용 제한 → 「사용하지 않는 앱 자동 절전」·「초절전 앱」 목록에서 빼기
      • 설정 → 애플리케이션 → 서울 1박 2일 → 「알람 및 리마인더」 허용
      • 최근 앱에서 밀어 닫는 것은 괜찮지만, 「강제 중지」는 예약을 지웁니다. 그랬다면 앱을 한 번 열면 다시 예약됩니다.

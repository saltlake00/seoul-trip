    예약된 알림
      알림이 안 오나요?

      배터리 제한을 풀어 주세요

      설정 → 애플리케이션 → 서울 1박 2일 → 배터리 → 「제한 없음」

      삼성은 설정 → 배터리 → 백그라운드 사용 제한에서 이 앱을 「사용하지 않는 앱 자동 절전」과 「초절전 앱」 목록에서 빼 주세요.

      알림이 늦게 오면

      설정 → 애플리케이션 → 서울 1박 2일 → 「알람 및 리마인더」를 허용해 주세요.

      앱을 닫았을 때

      앱을 닫아도 알림을 받을 수 있어요. 최근 앱에서 밀어 닫는 것은 괜찮지만 「강제 중지」를 하면 예약이 지워져요.

      「강제 중지」를 했다면 앱을 다시 한 번 열어 주세요. 그러면 다시 예약돼요.

# 회의 후 사이트 갱신 절차

일행은 노션에 자유롭게 적고, 회의가 끝나면 한 사람이 정리해서 사이트를 갱신한다.

```
노션 (자유 메모) → 회의록/날짜.md (로컬, 커밋 안 함) → AI가 data/trip.js 갱신 → 확인 → 커밋·push
```

## 1. 노션 내용 가져오기

- 노션 페이지에서 전체 선택(Ctrl+A) → 복사 → `회의록/2026-10-20.md` 같은 파일에 붙여 넣는다.
- `회의록/` 폴더는 `.gitignore`에 있어 GitHub에 올라가지 않는다. 일행 이름이 들어 있어도 괜찮다.

## 2. AI에게 맡기기

Claude Code에서 이 폴더를 열고 아래처럼 요청한다.

> `회의록/2026-10-20.md`를 읽고 `data/trip.js`를 갱신해줘. `docs/갱신-가이드.md`의 규칙을 따라.

### AI가 지킬 규칙

1. **공개 금지 정보**: 일행 실명·닉네임, 연락처, 예약번호, 숙소 상세 주소(개인 숙소일 때)는 `trip.js`에 넣지 않는다.
   누가 제안했는지도 적지 않는다.
2. **확정과 후보 구분**: 회의에서 정해진 것만 `status: "확정"`. 의견만 나온 것은 `"후보"`, 아예 미정이면 `pending`에 질문 형태로 넣는다.
3. **좌표**: 유명 장소는 좌표를 채운다. 식당처럼 위치가 애매한 곳은 좌표를 추정하지 말고 보고에 "좌표 확인 필요"로 적는다.
   (지도에서 엉뚱한 곳을 가리키는 것이 빈칸보다 나쁘다.)
4. **이동(move)**: 이전 장소에서 오는 방법과 대략적인 시간. 지하철이면 `detail`에 노선을 적는다.
5. **시간 순서**: 각 일자의 `items`는 시간순으로 둔다. 지도 동선 선이 이 순서를 따른다.
6. `updated`를 오늘 날짜로 바꾼다. 실제 일정이 들어가면 `sample: false`.
7. 마지막에 **바뀐 점 요약**과 **결정이 필요한 것**을 보고한다 — 다음 회의 안건이 된다.

## 3. 확인

- `python -m http.server 8792` 후 `http://localhost:8792`를 연다.
- 각 장소의 "위치 보기"를 눌러 카카오맵에서 위치가 맞는지 본다.

## 4. 배포

```bash
git add -- data/trip.js
git commit -m "일정 갱신: 10/20 회의 반영"
git push
```

push 후 1~2분 뒤 GitHub Pages 주소에 반영된다.
